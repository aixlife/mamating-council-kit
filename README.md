# AI 카운슬 킷

같은 질문을 여러 AI에게 동시에 던져 답을 나란히 받아보는 도구입니다.
원본: [aixlife/council-cli](https://github.com/aixlife/council-cli) (MIT) — 이 저장소는 마마팅 hq 이식용 전달본입니다.

- API 키가 필요 없습니다. 이미 로그인해서 쓰는 AI 프로그램들을 그대로 부릅니다.
- 설치 안 된 AI는 알아서 건너뛰고, 깔려 있는 것들만 소집됩니다.
- 승자를 정해주지 않습니다. 서로 다른 의견을 보는 게 목적이고, 결정은 사람이 합니다.

## 설치

`설치안내.md` 를 그대로 따라 하면 됩니다. 요약:

1. `council.mjs` 를 hq 저장소의 `업무자동화/카운슬/` 폴더에 넣는다 (브랜치로 올려 대표님 확인 후 합침)
2. `설치안내.md` 안의 규칙 블록을 hq 루트 CLAUDE.md에 붙인다
3. 클로드에게 "카운슬 불러줘" 라고 말하면 동작한다

## 동작 조건

- 클로드 말고 다른 AI 프로그램이 최소 하나 더 설치·로그인된 컴퓨터에서만 의미가 있습니다.
- 웹에서 여는 클로드 세션은 매번 새 컴퓨터라 다른 AI가 없어서 안 됩니다.
- 다른 AI 구독이 생기면 설치만 하면 자동으로 패널에 들어옵니다. 설정 변경이 필요 없습니다.
